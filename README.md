# POLITICA-DE-PRIVACIDAD
1. Datos personales

Focus Office no recoge, no solicita y no almacena datos personales. No hay registro de cuentas, ni nombre, ni correo electrónico, ni número de teléfono. No se accede a contactos, cámara, micrófono, ubicación ni archivos del dispositivo.

2. Datos guardados en tu dispositivo

La app guarda únicamente tus preferencias (duración de concentración y descanso, tema claro u oscuro, volumen y número de sesiones completadas) en el almacenamiento local del propio dispositivo. Esa información nunca se envía a ningún servidor y se borra al desinstalar la app.

3. Servicio de clima

Para mostrar el tiempo de Pekín, Moscú, Helsinki y Nueva York, la app consulta la API pública de Open-Meteo (open-meteo.com) usando coordenadas fijas de esas cuatro ciudades. No se envía ninguna información sobre ti ni sobre tu ubicación. Consulta la política de Open-Meteo en https://open-meteo.com/en/terms

4. Audio

La música y el sonido de lluvia se generan en tiempo real dentro del dispositivo. No se descargan archivos ni se transmite audio desde servidores externos.

5. Publicidad y análisis

Focus Office no incluye publicidad, ni rastreadores, ni herramientas de análisis de terceros.

6. Menores

La app no recoge datos de ningún usuario, incluidos los menores de edad.

7. Cambios en esta política

Si en el futuro la app incorpora funciones que traten datos, esta página se actualizará y se indicará la fecha del cambio.
